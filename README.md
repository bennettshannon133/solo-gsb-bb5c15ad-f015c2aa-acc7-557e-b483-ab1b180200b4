# 多色滚筒套准校核

印花车间多色滚筒对花（套准点）校核工具。输入各**色筒的重复周长**与**标记偏移**以及**布长**，自动计算：

- 从布头 `0 mm` 起**首次同时对花的位置**；
- 对花的**共同重复周期**（所有周长的最小公倍数）；
- 当多色永不对花时，指出**一对互不相容的色筒**及原因；
- 布长范围内**最早的 20 个对花位置**及布内对花点总数。

方案可命名保存到**本地 JSON 文件**，随时下拉切换、修改、删除。所有整数运算基于 BigInt，**周长、偏移、布长与计算结果均可超过 JavaScript 安全整数范围（2⁵³−1）**，位数无实际限制。

技术栈：Node.js + Express（后端）+ 原生 HTML/CSS/JavaScript（前端，无框架无打包）。

## 一条命令启动（Docker Compose）

```bash
docker compose up -d --build
```

启动后浏览器访问：

- **地址：** <http://localhost:3000>
- **端口：** 容器内 `3000`，默认映射到宿主机 `3000`

```bash
docker compose down        # 停止（保留数据卷）
docker compose logs -f     # 查看日志
```

## 使用说明

1. 在「方案参数」中填写方案名称。
2. 为每个色筒填写：
   - **重复周长 (mm)**：正整数；
   - **标记偏移 (mm)**：非负整数，且必须严格小于该筒周长。
3. 色筒数量可在 **2～8** 之间增减（「＋ 添加色筒 / － 移除末筒」，或行尾 ✕）。
4. 填写**布长 (mm)**：非负整数。
5. 参数修改后右侧**自动实时校核**（无需点击）；点击「保存方案」持久化，之后可在顶部下拉框切换、修改后再次保存，或删除。

所有输入只接受十进制整数字符（如 `123456789012345678901234567890`），不接受小数、科学计数法或正负号。

### 存储格式

所有方案保存在 `$DATA_DIR/plans.json`，单文件、UTF-8、可直接备份：

```json
{
  "plans": [
    {
      "id": "uuid",
      "name": "花型A-四色",
      "clothLength": "50000",
      "rollers": [
        { "perimeter": "640", "offset": "120" }
      ],
      "createdAt": "2026-01-01T00:00:00.000Z",
      "updatedAt": "2026-01-01T00:00:00.000Z"
    }
  ]
}
```

数值以**十进制字符串**存储，避免任何精度损失。写入采用临时文件 + 原子 rename。

## 计算原理（广义中国剩余定理）

从布头 `0 mm` 起，色筒 *i* 的标记出现在满足下式的所有位置：

```
x ≡ offset_i (mod perimeter_i)
```

多色同时对花，即求解该同余方程组（**广义 CRT**）。逐对合并两个同余式：

```
x ≡ r₁ (mod m₁),  x ≡ r₂ (mod m₂)
令 g = gcd(m₁, m₂)
有解条件：g 整除 (r₂ − r₁)
有解时合并为：x ≡ r (mod lcm(m₁,m₂))，r 为最小非负解
```

- 全部合并成功：
  - **首次同时对花位置** = 最终最小非负解 `r`（`0 ≤ r < L`；所有偏移均为 0 时为布头 `0 mm`）；
  - **共同重复周期** = `L = lcm(所有周长)`，之后每隔 `L` mm 重复一次对花。
- 某次合并不满足可解条件，则方程组**无解**：该色筒与基准筒永远无法同时出现标记。应用返回这对互不相容的色筒（编号、周长、偏移及二者 gcd）。数学上可证明，方程组无解当且仅当存在这样一对不相容的色筒。

布长 `M` 内的对花位置为序列 `r, r+L, r+2L, …` 中满足 `0 ≤ x ≤ M` 的位置（**含布头 0 和布尾端点 M 两个边界**）：

- 布内总数 = `r ≤ M ? ⌊(M − r)/L⌋ + 1 : 0`（直接用大整数除法统计，即便布长极大也不会逐点循环）；
- 页面只展示其中**最早的 20 个**，超出时注明总数。

全部计算使用 ES2020 `BigInt`，HTTP 传输与 JSON 存储均为十进制字符串，前端不做 `Number` 转换。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET | `/api/plans` | 方案列表 |
| GET | `/api/plans/:id` | 单个方案 |
| POST | `/api/plans` | 新建方案（校验后保存） |
| PUT | `/api/plans/:id` | 修改方案 |
| DELETE | `/api/plans/:id` | 删除方案 |
| POST | `/api/analyze` | 只计算不落盘（编辑时实时校核用） |

请求体示例：

```json
{
  "name": "花型A",
  "clothLength": "50000",
  "rollers": [
    { "perimeter": "640", "offset": "120" },
    { "perimeter": "720", "offset": "200" }
  ]
}
```
